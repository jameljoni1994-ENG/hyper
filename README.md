# Does the Convergence Threshold Matter? Sensitivity Theory and a Rate-Based Hybrid for First-to-Second-Order Switching

**حساسية عتبة التحويل في الطرق الهجينة وخوارزمية RH القائمة على المعدلات المحققة**
*(ملخص عربي في الأسفل — Arabic summary below)*

Hybrid optimizers run a cheap first-order (FO) phase, then switch to a
second-order (SO) method when the gradient norm drops below a threshold
`theta`. The folklore value is `theta = 1e-3`. **We show that this
default is indefensible**: the total-cost-vs-threshold curve changes
shape — even the direction of sensitivity — across problem families,
and we replace manual tuning with **RH**, a self-tuning hybrid driven
by *realized* convergence rates.

## Key findings

| Finding | Evidence |
|---|---|
| Cost vs. theta is monotone on some families, flat-interior on others, and catastrophic in both directions on others | E7 sweep: 15 thresholds x 10 seeds x 4 problems (`results/figs/F1`) |
| Folklore 1e-3 is mid-pack everywhere: up to **9.8x** off best (a9a), **16x** (quadratic); 10^2-too-small costs up to **44x**; 5x-too-large costs up to **40x** (log-sum-exp) | E7 medians |
| Insensitivity is *theoretically conditional*: closed-form optimum theta*, quadratic penalty for mispricing, exact basin-entry gate | THEORY.md + Appendix A |
| Optimizing the model online from logged estimates systematically recommends "never switch" (defects D1-D3) | v1 logging study |
| RH lands untuned in the top two on real data (a9a: 1.22x of best; beats its fixed-threshold ancestor by up to 7.8x) with zero Hessian products in phase 1 | E6 LIBSVM profile |
| RH is globally convergent by construction; probe overhead bounded; no unproductive SO stay exceeds one stagnation window | Appendix A (Lemma A1-A4, Theorem A3) |

## Quickstart

```bash
# environment: Python >= 3.11 with numpy + matplotlib
pip install numpy matplotlib

# 1. functional + theory checks (must pass before any expensive run)
python code/tests/check_v2.py
python code/tests/theory_check.py      # exits 0 iff 13/13 pass

# 2. fetch LIBSVM datasets into data/ (a9a, mushrooms, w8a)
python code/problems_real.py

# 3. run an experiment slice (append-only CSV ledger)
```

### Wall-clock honesty

All timings are single-threaded wall-clock medians over seeds; timing
experiments must never overlap (hence the sequential supervisor).
Non-convergence within a per-run cap is *reported*, never imputed.
Any semantic change to a method triggers a full purge of that method's
rows (see `docs/PROGRESS.md`, purge ledger).

## The RH design contract (summary)

1. Rate estimator = least-squares slope of last m=30 log-gradient
   values; trusted only if window span, `rho_hat in (0,1)` and residual
   gate all pass.
2. Pessimistic switch prior `c2_eff = 100*c1_hat` until first measured
   SO squaring count (earliness costed us 6x once).
3. Arm A fires on validated economics AND `g <= 0.5*g0`.
4. Desperation arm B probes after 5 stalled inspection points.
5. Probe acceptance is two-stage: strict gradient-norm decrease first
   (float-floor-safe), else Armijo; fails only if neither arm certifies
   any step.
6. Stagnation monitor: <2% relative decrease per 50 iters => revert to
   phase 1 with escalated parameters.

Formal statements and proofs: `paper/paper_en.pdf`, Appendix A.
